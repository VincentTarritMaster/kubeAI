Commandes de test sur une machine 32 Go :

  git pull
  .\scripts\stop.ps1
  .\scripts\start.ps1

Si PowerShell refuse le script non signé :

  powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\start.ps1

Vérification cAdvisor :

  Invoke-RestMethod http://127.0.0.1:8000/capabilities
  Invoke-RestMethod http://127.0.0.1:8000/cluster/status
  python scripts\verify-observability.py --context docker-desktop --require-container-metrics

Attendu :
- cadvisor = available ;
- data_status = complete ;
- container_metrics = available ;
- CPU et mémoire non nuls.

DÉMO A/B/C
Lancer un nouveau scénario :

  .\scripts\run-demo-incident.ps1
  python scripts\verify-demo-metrics.py --context docker-desktop

Puis, dans Open WebUI, poser B/C avec les horodatages UTC affichés par le
script. Exemple avec une ancienne fenêtre déjà collectée :

  Corrèle les logs, le CPU et les erreurs HTTP de l’incident du pod kubeai-demo-incident dans le namespace kubeai, le 22 octobre 2026 entre 19:36 et 19:41 UTC.

Attention au fuseau :
- le script affiche l’UTC ;
- Open WebUI affiche l’heure suisse (UTC+2) ;
- 19:36 UTC = 21:36 en Suisse ;
- ne pas utiliser 23:36, qui correspond à 21:36 UTC, hors scénario.

SÉCURITÉ
cAdvisor est lu via nodes/proxy. Alloy possède list/watch sur nodes et get sur
nodes/proxy, en lecture seule. Le collecteur n’est ni privilégié ni monté sur
l’hôte. C’est le compromis nécessaire pour les métriques conteneur.

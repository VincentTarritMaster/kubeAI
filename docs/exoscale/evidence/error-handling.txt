Protocole :
- KUBEAI_TOOL_PROTOCOL=json ;
- parsing JSON tolérant aux fences Markdown mais strict sur les clés ;
- budget de tokens des appels d'outils porté à 1024 ;
- un retry explicite sur appel d'outil invalide ;
- erreur SSE terminale avec code, message localisé et diagnostic_id ;
- réponse non-streaming en HTTP 503 avec le même contrat ;
- avertissement « Diagnostic partiel » ajouté quand une source a réellement
  échoué (Mimir, Loki, Kubernetes ou métriques d'inventaire).
